# EcoPower Grid - Incident Analysis & Secret Management

## Contexto del Proyecto
EcoPower Grid administra sistemas de telemetría y control remoto para subestaciones eléctricas y redes de distribución inteligente (Smart Grids). Se detectó un incidente crítico de seguridad donde tokens de control industrial y credenciales de bases de datos de monitoreo fueron filtrados por 72 horas.

## Objetivo de la Actividad
El equipo debe analizar los impactos de esta filtración, evaluar los vectores de exposición, diseñar un plan de respuesta a incidentes inmediato y proponer una arquitectura segura basada en gestión centralizada de secretos.
